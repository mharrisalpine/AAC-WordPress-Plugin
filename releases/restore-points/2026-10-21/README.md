# Pre-install restore point

The ZIP is the 1.0.834 package installed on WP Engine before the PMPro Member Information editor change. To restore plugin files, upload this ZIP through WordPress Plugins and choose Replace current with uploaded.

This restores plugin code only; it is not a database backup.
