# AAC Portal Theme

This is a starter WordPress theme scaffold based on the AAC member portal visual system.

## What it includes

- AAC-style black header and top navigation
- editorial front page layout
- reusable page and index templates
- support for shared `aac_member_portal_settings` when the `aac-member-portal` plugin is active
- WordPress menu support for a real site nav

## How to use it

1. Upload `aac-portal-theme.zip` in `Appearance > Themes`.
2. Activate `AAC Portal Theme`.
3. Assign a menu to the `Primary Navigation` location.
4. Optionally set a custom logo in the WordPress Customizer.
5. If the AAC Portal plugin is active, many hero/content values will automatically reuse those stored settings.

## Why this exists

The member app plugin should keep doing plugin things:

- portal app logic
- member data
- Salesforce sync
- admin tools

The theme handles site-wide presentation:

- header
- typography
- page shell
- public landing pages
- reusable content templates
